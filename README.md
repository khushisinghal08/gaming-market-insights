# 🎮 Video Game Sales Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing video game sales data using MySQL to understand global market performance, popular gaming platforms, successful genres, publisher performance, and regional sales trends.

The objective is to explore the gaming industry through SQL queries and identify meaningful patterns from sales data.

## 🎯 Project Objectives
- Identify the top 10 best-selling video games.
- Analyze sales performance across different platforms and genres.
- Explore yearly global sales trends.
- Compare sales across different geographical regions.
- Identify top-performing publishers.
- Find games with sales higher than the overall average.

## 🛠️ Tools Used
- **Database:** MySQL
- **IDE:** MySQL Workbench
- **Language:** SQL

## 📂 Dataset
The project uses video game sales data containing:
- Game Name
- Platform
- Release Year
- Genre
- Publisher
- Regional Sales (North America, Europe, Japan and Other)
- Global Sales

## ⚙️ Project Process

1. **Database Design:** Created a relational database with primary keys, foreign keys, and normalized tables.
2. **Data Loading:** Imported CSV data into staging tables using `LOAD DATA INFILE`.
3. **Data Transformation:** Transferred data into structured tables and established relationships between games, platforms, genres, and publishers.
4. **Data Analysis:** Wrote SQL queries to explore sales performance and answer business questions.

## 📊 Key Analysis
- Top 10 best-selling games worldwide.
- Best-performing gaming platforms.
- Genre-wise global sales.
- Year-wise global sales trends.
- Top 5 publishers by global sales.
- Regional sales comparison and contribution percentage.
- Top 5 best-selling games in different regions.
- Average sales per game by publisher.
- Games performing above average global sales.

## 🗄️ Database Design
Designed a normalized relational database using primary keys, foreign keys, and separate tables for games, genres, platforms, publishers, and sales.

Bridge tables were also used to manage game-to-genre and game-to-team relationships.
